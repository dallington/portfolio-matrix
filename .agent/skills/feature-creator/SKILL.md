# Feature Creator

This skill helps design and create **new application features** with a clear and maintainable structure.

## When to use this skill

Use this skill when:
- Creating a new feature from scratch
- Translating requirements into implementation
- Defining folder structure and components

Do NOT use this skill when:
- Only small code changes are required

## How to use it

1. Identify feature scope
2. Define responsibilities
3. Propose folder structure
4. Create initial components and hooks
5. Keep implementation minimal and extensible

## Rules

- Feature-based folder structure is mandatory
- Avoid premature abstractions
- Favor clarity over completeness

## Expected Output

- Feature folder structure
- Initial implementation
- Clear separation of concerns
