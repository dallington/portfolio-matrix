# Blog Writer — Junior to Mid Level

This skill produces **educational, approachable technical blog posts** aimed at junior and mid-level developers.

## When to use this skill

Use this skill when:
- Writing blog posts for less experienced engineers
- Teaching concepts, tools, or patterns
- The goal is learning and clarity

Do NOT use this skill when:
- Writing deep architectural content
- The audience is senior-level

## How to use it

1. Introduce concepts gradually
2. Define terminology before using it
3. Use simple examples
4. Avoid deep architectural trade-offs unless necessary

## Writing Rules

- Friendly and explanatory tone
- Short paragraphs
- Practical examples
- Avoid heavy jargon

## Expected Output

- Beginner-friendly technical article
- Clear structure and examples
