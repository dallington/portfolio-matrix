# Technical Blog Writer

This skill enables the agent to write **deep, opinionated, technically rigorous blog posts** from the perspective of a senior software engineer.

## When to use this skill

Use this skill when:
- The user requests a technical blog post
- The content is engineering or architecture focused
- The goal is knowledge sharing, not marketing

Do NOT use this skill when:
- Writing beginner tutorials
- Producing marketing or SEO-driven content

## How to use it

1. Identify topic, audience, and depth
2. Structure the post logically:
   - Problem context
   - Constraints
   - Design decisions
   - Trade-offs
   - Outcomes
3. Focus on "why" and "how"
4. Use code and diagrams only when they add clarity

## Writing Rules

- Tone: confident, direct, evidence-based
- Avoid buzzwords and fluff
- Assume a technically competent reader
- Prefer TypeScript or backend examples

## Expected Output

- Publication-ready blog post
- Senior-engineer perspective
- Practical, experience-based insights
