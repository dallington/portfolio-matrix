# Case Study Writer

This skill produces **engineering-focused case studies** demonstrating real-world problem solving.

## When to use this skill

Use this skill when:
- Writing engineering case studies
- Showcasing project outcomes and decisions

Do NOT use this skill when:
- Writing marketing success stories
- Producing shallow summaries

## How to use it

Structure the case study as:

1. Problem
2. Constraints
3. Solution
4. Trade-offs
5. Results

## Writing Rules

- Use professional engineering language
- Explain reasoning behind decisions
- Highlight lessons learned
- Avoid buzzwords

## Expected Output

- Clear and structured case study
- Senior-level engineering thinking
